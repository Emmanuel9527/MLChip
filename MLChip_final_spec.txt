   Abstract—This final project implements a SystemC-based CNN
accelerator derived from the HW4 NoC baseline. The baseline
replaces ROM-based tensor access with an AXI4-like DMA
and DRAM model while preserving the original controller-
scheduled PE execution style. The optimized design introduces
explicit global SRAM, PE-local SRAM, DMA-to-SRAM data
movement, bounded controller registers, and a PE-level systolic
fully-connected dataflow mapped onto the original 4 × 4 NoC
mesh. The optimized FC classifier reuses the 16 original PEs as
two 2 × 4 MVM sub-arrays, overlaps FC weight prefetch with
computation through ping-pong SRAM buffers, and commits
final scores back to DRAM before output reporting.

                     VII. C ONCLUSION
   The baseline verifies the functional correctness of replac-
ing ROM accesses with AXI4-like DMA and DRAM while
preserving the HW4 computation structure. The optimized
design improves hardware realism and FC performance by
introducing explicit SRAM hierarchy, DMA-to-SRAM trans-
fers, bounded controller registers, and PE-level systolic MVM
mapping. The end-of-run metric report allows the comparison
table to be filled directly from SystemC execution logs.
